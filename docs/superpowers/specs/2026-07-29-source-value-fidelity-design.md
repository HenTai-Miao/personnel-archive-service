# Excel 来源值原样保真设计

> 2026-07-30 扩展：来源文本仍是展示与重建的唯一权威；在不改变原文的前提下，系统现会按 `chinese-source-value-projections-design.md` 额外保存可空数字组件。下文原先“解析值不入库/不存在第二投影”的限制已由该后续产品决定替代，禁止的仍是补齐精度或存储另一份格式化日期。

## 产品决定

工作簿中用户可见的业务值是唯一权威：传入什么就入库什么、接口返回什么、页面展示什么、导出什么。

- 日期只含年时保留年；只含年月时保留年月；含年月日时保留年月日。
- 不统一分隔符，不补缺失的月或日，也不把年月转换成每月第一日。
- 家庭成员的字面年龄逐字保存。只有主表单元格明确包含模板标准 `DATEDIF(家庭成员年龄计算!D<n>,TODAY(),"y")` 时，导入器按 Excel 语义得到导入日显示值并立即冻结为字符串；查询、页面和导出不再计算，也不追加“岁”。
- 空值保持空，不从其他字段推测。

## 领域与校验

`SourceDate` 保存来源文本，并根据来源实际精度携带可选的 `Year`、`YearMonth` 或 `LocalDate` 校验语义。这些解析值用于拒绝非法日期、校验未来出生日期，并生成只含来源明确组件的可空数字投影；它们不经 API 返回，也不能反向格式化来源文本。

读取器使用 Apache POI `DataFormatter` 读取工作簿已保存的文本与公式缓存。字面年龄不变；仅精确匹配模板标准年龄公式时，按其辅助表日期引用、`TODAY()` 和 `"y"` 语义冻结当前显示值，真正的空引用按 Excel 序列值 0 处理。其他公式只取缓存。年、年月和年月日均接受既有受支持格式；非空但非法的日期继续以安全的单元格坐标返回 `TEMPLATE_INVALID`。

`ArchiveDocument.FamilyMember.ageText` 接收字面年龄或导入时公式结果。辅助表出生日期仍只在主表公式明确引用或“称谓＋姓名”唯一精确匹配时关联；没有明确标准公式时不得从出生日期推导年龄。

学历、工作经历和奖惩行继续以 `raw_text` 与 `sort_order` 保证完整重建。可识别的开始、结束或发生日期仅截取来源字符串写入对应业务列，不做标准化。

## 数据库

Flyway V6 是过渡迁移：增加日期来源文本列和 `pa_family_member.age_text`，用于先保护已有来源值。

Flyway V7 将十二个业务日期列统一改为 `VARCHAR(64)`：

- `pa_person`：`birth_date`、`political_join_date`、`declaration_date`；
- `pa_employment`：`work_start_date`、`dispatched_to_bidding_company_date`、`title_or_skill_acquired_date`；
- `pa_education`：`start_date`、`end_date`；
- `pa_work_experience`：`start_date`、`end_date`；
- `pa_reward_punishment`：`occurred_date`；
- `pa_family_member`：`birth_date`。

V7 在改列后优先把 V6 的来源文本回填到原业务列，再删除所有临时 `*_date_text` 列。`age_text` 保留。最终模型没有第二套 `DATE` 或日期来源副本；后续 V9/V10 增加的仅是可空年/月/日和精确年龄数字组件，不能替代来源文本或补齐完整日期。

历史记录若在 V6 前已经只剩规范化后的完整日期，只能保留当时数据库可用的值；系统不猜测丢失的原始精度。之后重新导入的工作簿按新规则产生完整保真快照。

## API、客户端与导出

详情 API 的全部业务日期和家庭年龄字段都是来源字符串或空字符串。OpenAPI 与 B 客户端 Zod 契约同步使用字符串。

客户端直接展示这些字符串，不调用日期格式化器，不计算年龄，也不追加单位。导出器把数据库字符串写为 Excel 文本值；年、年月、年月日和年龄均保持数据库中的来源内容。

重复判断、覆盖快照、软删除、审计、照片和源工作簿不留存规则不变。

## 验证

- 读取器分别锁定年、年月、年月日、字面年龄、标准公式当前值和其他公式缓存值；不允许补月、补日或从非标准公式/其他字段推测年龄。
- 写库测试断言 Mapper 直接收到来源字符串。
- MySQL 8.4 迁移测试断言十二列为 `VARCHAR`、临时日期文本列已删除，并能保存不同日期精度与年龄文本。
- 详情与序列化测试断言 API 原样返回字符串。
- 导出后重开工作簿，断言年、年月、年月日和年龄文本不变。
- 完整导入集成测试核对数据库、详情和导出链路一致。

## 非目标

- 不保存上传源工作簿或用户公式本身；标准年龄公式只在导入边界得到一次当前显示值，其他公式不执行。
- 不追求逐字节重建 XLSX。
- 不从任何字段猜测年龄；只执行模板明确给出的标准年龄公式一次。不得修正日期精度。
- 不改变家庭成员出生日期的证据化关联规则。
