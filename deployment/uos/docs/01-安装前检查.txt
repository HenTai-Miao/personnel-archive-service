人员档案数据服务——安装前检查
================================

本包用于统信 UOS 离线电脑，后端使用 Java 21，连接同一台电脑上的 MySQL 8：
127.0.0.1:3306/personnel_archive。安装脚本不会联网下载软件，也不会安装系统软件包；
缺少条件时会停止并给出明确错误。

一、必须已经具备

1. 64 位统信 UOS，JDK/JRE 21 的架构与电脑一致。
2. MySQL 8 已安装并能由 systemd 管理。
3. 数据库 personnel_archive 和账号 personnel_archive@127.0.0.1 已创建，账号密码与
   本次交付的固定 prod 配置一致。
4. /data 已存在、不是符号链接，所在文件系统至少有 2 GiB 初始可用空间。
5. 系统已有 bash、systemd、sha256sum、ss、awk、grep、stat 等基本命令。
6. 当前操作人员能够使用 root 权限执行安装脚本。

二、在目标电脑检查 Java 和空间

    java -version
    java -XshowSettings:properties -version 2>&1 | grep java.specification.version
    uname -m
    sudo mkdir -p /data
    sudo chmod 0755 /data
    df -h /data

java.specification.version 必须是 21。Java 17、Java 8 或其他版本均不符合本包要求。
安装器不会修改已有 JDK/MySQL，也不会在 /data 不存在时擅自创建部署根目录。

三、传输与校验

推荐把同名 .tar.gz 和 .tar.gz.sha256 一起传到目标电脑，先在二者所在目录执行：

    sha256sum --check 人员档案数据服务-统信UOS离线部署-20260813.tar.gz.sha256

文件名若有 -1、-2 等防覆盖后缀，应使用实际名称。校验成功后再解压。也可以把离线
目录内文件一个一个传递，但目录层级和文件名必须原样保留。全部传完后执行：

    sha256sum --check SHA256SUMS

install.sh 会在安装开始时再次执行内部校验。任何一项不是 OK，都应重新传输损坏或
遗漏的文件，不能继续安装。

四、固定数据库配置与敏感信息

按你的部署要求，prod 的 MySQL 地址、账号和已提供密码已经固定写入生产配置并包含在
JAR 中，安装器不会再次询问或覆盖。离线包因此属于公司内部敏感交付物，只能传到指定
离线服务器；不要上传公网或转交无关人员。不要粘贴到聊天。不要保存到普通文本文件。

离线包不包含个人档案、上传的 Excel、照片或数据库导出。数据库连接和三项安全值已经
固定在 prod 并包含在 JAR 中，因此 JAR 本身属于敏感生产安装介质；不要上传公网、粘贴
到聊天或转交无关人员。目标电脑不需要另外生成或填写三项安全值。

五、数据库授权先决条件

安装前按 02-数据库授权.txt 执行库级 GRANT 和 SHOW GRANTS。随包 SQL 不创建账号、
不修改密码。安装器不会代替数据库管理员执行 SQL，制作电脑也不会连接离线数据库。
