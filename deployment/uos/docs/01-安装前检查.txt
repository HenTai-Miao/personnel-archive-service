人员档案数据服务——安装前检查
================================

本包用于统信 UOS 离线电脑，后端使用 Java 21，并连接同一台电脑上的
MySQL 8：127.0.0.1:3306/personnel_archive。安装脚本不会联网下载软件，也不会
安装系统软件包；缺少条件时会停止并给出固定错误。

一、必须已经具备

1. 64 位统信 UOS，JDK/JRE 21 的架构与电脑一致（例如 x86_64 或 aarch64）。
2. MySQL 8 已安装并能由 systemd 管理。
3. 数据库 personnel_archive 和应用账号 personnel_archive@127.0.0.1 已创建。
4. /opt 所在文件系统至少有 2 GiB 可用空间。
5. 系统已有 bash、systemd、openssl、sha256sum、ss、awk、grep 等基本命令。
6. 当前操作人员能够使用 root 权限执行安装脚本。

二、在目标电脑检查 Java 和空间

    java -version
    java -XshowSettings:properties -version 2>&1 | grep java.specification.version
    uname -m
    df -h /opt

java.specification.version 必须是 21。不要因为命令能运行就忽略版本；Java 17、
Java 8 或其他版本均不符合本包要求。

三、传输与校验

推荐把同名 .tar.gz 和 .tar.gz.sha256 一起传到目标电脑，先在二者所在目录执行：

    sha256sum --check 人员档案数据服务-统信UOS离线部署-20260813.tar.gz.sha256

如果文件名带 -1、-2 等防覆盖后缀，应使用实际文件名。校验成功后再解压。

也可以把离线目录中的文件一个一个传递，但目录层级和文件名必须原样保留。
全部传完后，进入离线目录执行：

    sha256sum --check SHA256SUMS

install.sh 还会在安装开始时重新执行同一份内部校验。任何一项不是 OK，都不要
继续安装，应重新传输损坏或遗漏的文件。

四、密码与人员数据安全

附件中出现过的旧应用数据库密码已经不能用于生产，必须按 02 文档轮换。
新密码只在 MySQL 终端读取一次，然后直接输入 install.sh。不要粘贴到聊天，
不要保存到普通文本文件，也不要截屏。安装脚本输入时不回显，不使用命令跟踪，
不会把密码或三项安全密钥写入安装日志。

离线包不包含数据库密码、个人档案、上传的 Excel、照片、现有环境配置或开发
配置。安装前不要自行往包内添加这些内容，否则 SHA-256 校验无法再证明原包完整。

五、数据库授权先决条件

在运行安装脚本之前，完成 02-数据库授权.txt 中的密码轮换、授权和 SHOW GRANTS
核对。安装脚本不会代替数据库管理员执行 SQL，也不会从制作电脑连接离线数据库。
